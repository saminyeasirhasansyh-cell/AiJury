# Screenshot provenance

These JPEG files are unmodified full-page browser captures of the app served locally with `npm run build` and `npm start` from this repository on November 8, 2026 (America/New_York).

- `jury-room.jpg`: initial case intake and empty jury room.
- `demo-verdict.jpg`: built-in fictional demo after revealing the verdict, with Arguments selected.
- `evidence-review.jpg`: the same completed fictional demo, with Evidence selected.

Captured through the Codex in-app browser after the preferred agent-desktop interface reported inaccessible browser windows. Demo playback was paused before the final captures. No API key, real case data, paid generation, mockup, or generated image was used. The responsive layout reflects the capture browser's default viewport.

To reproduce, run the app, open http://localhost:10000, capture the initial page, choose Watch a demo, pause playback, choose Skip to the verdict, and capture the Arguments and Evidence views.
